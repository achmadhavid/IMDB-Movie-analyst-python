Analisis data eksploratif (EDA) terhadap dataset film IMDB menggunakan Python untuk memahami tren perilisan dan karakteristik film.

## 📸 Preview

![Movie released each year](Movie%20released%20each%20year.png)

## 📌 Ringkasan Proyek

Proyek ini mengeksplorasi dataset `imdb_movies.csv` untuk menjawab pertanyaan seperti jumlah film yang dirilis tiap tahun serta pola lain pada data film. Hasil notebook juga diekspor ke format HTML agar bisa dibaca tanpa menjalankan kode.

## 🎯 Tujuan

- Memahami struktur dan kualitas dataset film IMDB.
- Menganalisis tren jumlah film yang dirilis setiap tahun.
- Menyajikan hasil dalam bentuk visualisasi yang mudah dipahami.

## 🛠️ Tools

- **Python**
- **Jupyter Notebook**
- **CSV** sebagai sumber data

## 📁 Struktur Repository

```
IMDB-Movie-analyst-python/
├── imdb_movies.csv              # Dataset film
├── Untitled.ipynb               # Notebook analisis
├── IMDB movie analyst.html      # Hasil notebook (versi HTML)
├── Movie released each year.png # Visualisasi jumlah film per tahun
└── README.md
```

## 🚀 Cara Menjalankan

1. Clone repository:
   ```bash
   git clone https://github.com/achmadhavid/IMDB-Movie-analyst-python.git
   cd IMDB-Movie-analyst-python
   ```
2. Install library yang dibutuhkan:
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```
3. Jalankan `jupyter notebook`, lalu buka `Untitled.ipynb`.
4. Atau lihat hasil langsung lewat file `IMDB movie analyst.html`.
